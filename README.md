# Voice Accent Trainer & Listener

An interactive, browser-based web application designed to help non-native English speakers practice their pronunciation, work on their accent accuracy, and break away from traditional "translation-based" learning. 

Instead of translating text back and forth, this app encourages users to speak out loud, delivering immediate, visual feedback on their spoken accuracy.

## 🚀 Features

- **Real-Time Speech Recognition:** Utilizes the Web Speech API to listen to user speech with zero lag.
- **Accent Forgiveness Loop:** Scans the top 5 alternative guesses generated by the speech engine to accommodate unique accents without discouraging the learner.
- **Dynamic Text Highlighting:** Automatically parses user input text and highlights the currently expected word using interactive `<mark>` cues.
- **Session Control:** Complete playback control with Play, Stop, Restart, and Manual Skip capabilities.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3
- **Scripting Engine:** Vanilla JavaScript (ES6+)
- **API Integration:** Web Speech API (`SpeechRecognition`)

## ⚙️ How It Works

1. Paste any English text or essay into the main textarea.
2. Click **Play** to initialize the speech recognition engine.
3. Read the highlighted word aloud. 
4. If your pronunciation matches one of the API's top 5 internal guesses, the application automatically increments to the next word and shifts the highlight framework forward.
5. Use the **Skip** button to manually pass problematic words or homophones.
